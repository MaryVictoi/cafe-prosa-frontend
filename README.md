## 📌 Sobre o Projeto

O **Café & Prosa** foi desenvolvido como um projeto prático para consolidar conceitos de desenvolvimento front-end e design de interfaces (UX/UI). O objetivo principal foi traduzir um protótipo navegável criado no Figma em uma aplicação web funcional, acessível e totalmente responsiva.

A identidade visual transmite aconchego e modernidade através de tons terrosos (marrom, bege e caramelo), pensados estrategicamente para refletir a atmosfera acolhedora de uma cafeteria artesanal.

---

## 🎯 Objetivos

- **Design UI/UX:** Converter wireframes e protótipos de alta fidelidade em código limpo.
- **Semântica Web:** Estruturar a página utilizando as tags semânticas do HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- **Arquitetura CSS:** Trabalhar com Variáveis CSS (*Custom Properties*) para manter o código modular e escalável.
- **Layout Responsivo:** Implementar Flexbox e CSS Grid para adaptação fluida em dispositivos móveis, tablets e desktops.

---

## ✨ Funcionalidades

- 📱 **Layout 100% Responsivo:** Adaptação dinâmica para qualquer tamanho de tela.
- 🎨 **Paleta Temática:** Cores selecionadas para criar uma experiência imersiva.
- ☕ **Apresentação de Produtos:** Cards estilizados para cafés especiais e pães artesanais.
- 💻 **Espaço Coworking:** Seção dedicada para divulgação da área de estudos e trabalho.
- 🚀 **Navegação Fluida:** Cabeçalho estruturado com menu de navegação e chamadas para ação (*CTA*).
